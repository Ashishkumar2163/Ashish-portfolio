# Ashish Kumar Jha — Portfolio

A responsive React + Vite portfolio for Ashish Kumar Jha, Full Stack Developer.

## Tech
- React.js
- Vite
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Before publishing
1. Add project-specific GitHub repository links when the repositories are ready.
2. Add a deployed portfolio URL to the resume.
3. If you later create a PDF resume, add a Resume download button to the hero.
